Privacybeleid – Byte Assistent

Laatst bijgewerkt: 24 november 2026

Wat is Byte Assistent?

Byte Assistent is een persoonlijke assistent die alleen door de eigenaar, Furbyte, wordt gebruikt. De app draait op een eigen server bij hem thuis en is niet bedoeld voor andere gebruikers.

Welke gegevens gebruikt de app?

  • Gmail: mails lezen, labelen, als gelezen markeren en conceptantwoorden maken. Een mail wordt pas verstuurd nadat de eigenaar daar zelf op klikt.
  • Google Agenda: afspraken lezen, toevoegen, wijzigen en een kleur geven.

Waar blijven de gegevens?

De gegevens worden verwerkt op de eigen server van de eigenaar. Voor het samenvatten en beantwoorden van vragen wordt tekst naar Google Gemini gestuurd. De gegevens worden niet verkocht, niet gedeeld met andere partijen en niet gebruikt voor reclame.

Google API-gegevens

Het gebruik van gegevens uit Google API's voldoet aan het Google API Services User Data Policy, inclusief de eisen voor beperkt gebruik (Limited Use).

Toegang intrekken

Je kunt de toegang van de app op elk moment intrekken via myaccount.google.com/permissions.

Contact

Vragen over dit privacybeleid? Mail naar thijsvandescheur@gmail.com.

English summary: Byte Assistent is a private assistant used only by its owner. It accesses Gmail and Google Calendar to read, label and draft emails and manage calendar events; emails are only sent after the owner approves them. Data is processed on the owner's own server and by Google Gemini, is never sold or shared with third parties, and Google API data use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
